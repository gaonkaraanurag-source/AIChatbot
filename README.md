# AIChatbot
Project Description
Created a Python-based AI analytics assistant that uses LangChain and Groq to analyze sales and marketing campaign data. The project started as a simple LLM chatbot and evolved into a data-driven insights tool that loads campaign data from a CSV file, calculates key business metrics with pandas/NumPy, and uses an AI model to explain insights in natural language.
The assistant helps answer questions about campaign performance, customer behavior, product category sales, total revenue, top customers, and promotion success.
